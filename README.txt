TIRLA VENTURES WEBSITE

How to open:
1. Unzip this folder.
2. Right-click index.html > Open With > Google Chrome (or Safari / Edge).
   Do NOT use a preview window (Mac spacebar Quick Look, email/WhatsApp previews, or the Claude app preview) - those do not run animations or 3D.

Everything (3D engine, fonts, animations) is inside index.html. No internet needed.
To put it online: upload index.html to Netlify Drop (app.netlify.com/drop), Vercel, or any web host.
